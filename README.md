# 🌐 Portfólio Cybernético  

Bem-vindo ao meu **Portfólio Cybernético**, um projeto interativo e visualmente imersivo que reúne minhas habilidades, experiências e criações em um ambiente digital com estética futurista e cyberpunk.  

## 🚀 Sobre o Projeto  
Este portfólio não é apenas um site de apresentação, mas uma **experiência interativa**.  
A proposta é unir design moderno com uma pegada **cybernética**, criando uma interface envolvente que reflete minha identidade criativa e técnica.  

## ✨ Funcionalidades  
- 🎨 **Design Futurista:** estética inspirada em cyberpunk, neon e glitch.  
- 🖥️ **Seções Interativas:** apresentação de projetos, habilidades e contato.  
- ⚡ **Animações Dinâmicas:** partículas, efeitos visuais e transições suaves.  
- 📱 **Responsividade:** adaptado para desktop, tablet e mobile.  

## 🛠️ Tecnologias Utilizadas  
- **HTML5**  
- **CSS3** (com animações avançadas e efeitos visuais)  
- **JavaScript (ES6+)**  
- **Bootstrap** (estrutura responsiva)
